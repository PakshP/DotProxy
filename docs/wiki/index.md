# DotProxy Wiki

Welcome to the DotProxy wiki.

DotProxy is a lightweight AFK proxy for Minecraft. It keeps one account online on any server, so AFK farms keep running while you're away. You can join the proxy from your own Minecraft client at any time to take control of the account.
